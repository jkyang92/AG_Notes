\section{Using the Macaulay2 Package}

The Macaulay2 code is currently contained in the \texttt{HHLResolutions} package. As this is not a package distributed with Macaulay2 using it is slightly harder than usual. In particular you need to be aware of where the code is actually located on your computer. This tutorial will assume that you have Macaulay2 installed and have some familiarity with using it. %\jay{Include directions on installing Macaulay2 and a link to a basic tutorial}

\subsection{Basic Usage and Installation}
The most direct way is to call \verb|needsPackage| with the file name specified. For instance if the file \verb|HHLResolutions.m2| is in the folder \verb|/home/username/code/|, then one can run the following to load the package.

\begin{verbatim}
needsPackage("HHLResolutions", FileName=>"/home/username/code/HHLResolutions.m2")
\end{verbatim}

Then we can use this for example to compute a resolution for the diagonal in $\mathbb{P}^2\times \mathbb{P}^2$.

\begin{verbatim}
needsPackage("HHLResolutions", FileName=>"/home/username/code/HHLResolutions.m2")
X = toricProjectiveSpace 2;
Y = X ** X; -- This is the cartesian product X \times X
phi = diagonalToricMap(X); -- This is the diagonal map from X into X \times X
hhlResolution(phi)
\end{verbatim}

The documentation of the package is viewable by using viewHelp
\begin{verbatim}
needsPackage("HHLResolutions", FileName=>"/home/username/code/HHLResolutions.m2")
viewHelp HHLResolutions
\end{verbatim}

If you wish to install the package for your version of Macaulay2, then you can run the following. It would need to be run every time the package is updated, however after the package is installed, one can run needsPackage from anywhere without worrying about the \verb|FileName| parameter.
\begin{verbatim}
--This needs to be run from the folder containing the HHLResolutions.m2 file
installPackage("HHLResolutions")
\end{verbatim}
You can also provide a FileName parameter to installPackage if you wish. Installing the package is \textbf{NOT} required.

\subsection{Computing Resolutions}

To get a resolution for a toric subvariety, you should use the \texttt{hhlResolution} function. This function currently supports two ways of being called, First is to give it a toric map, represented by a \texttt{ToricMap} object as seen previously.

For example, we can recover the examples from Section~\ref{lec:7-HHL-construction} as follows
\begin{verbatim}
X = affineSpace 2
Y = affineSpace 1
S = ring X
f = map(X,Y,map(ZZ^2,ZZ^1,matrix {{1},{1}}})
hhlResolution(f)
g= map(X,Y,map(ZZ^2,ZZ^1,matrix {{2},{3}}})
hhlResolution(g)
\end{verbatim}

For the resolution of a point, NormalToricVarieties will not allow maps to and from a single point, so we need to use the alternate format

\begin{verbatim}
X = hirzebruchSurface 3
S = ring X
hhlResolution(X,map(ZZ^(dim X),ZZ^0,0))
\end{verbatim}

\subsection{Bondal Thomsen Monads of Line Bundles}

There is also support for obtaining the result of Fourier-Mukai of line bundles against the HHL resolution of the diagonal.
\begin{verbatim}
X = hirzebruchSurface 3
S = ring X -- the ring has variables x_0,x_1,x_2,x_3
a = {0,0,2,-1} --this is the exponent vector of the monomial x_2^2/x_3
lineBundleBondalThomsenMonad(X,a)
\end{verbatim}



\subsection{Other Functions of Note}

There are a few other functions which may potentially be of interest, although in most cases the functions previously described suffices for accessing the functionality of the package.
\begin{description}
\item[\texttt{hhlVectors}] The cell complex supporting the resolution is cut out by hyperplanes, this returns the normals of those hyperplanes
\item[\texttt{bondalThomsenStrata}] This function returns the cells on a fundalmental domain that correspond to the Bondal-Thomsen strata grouped by stratum.
\item[\texttt{hhlPolytopes}] This function returns the cells on a fundamental domain that are used to construct the resolution. This is primarily intended for internal use so the output is somewhat inscrutible. See Section~\ref{lec:7-HHL-construction} for the construction.
\end{description}

There are other functions, however nearly all of the rest are either not relevant to the questions posed here or are intended to expose certain internal details.
